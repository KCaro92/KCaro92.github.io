# KCaro92.github.io

Godot World Assignment. I followed the 2D tutorial on Godot and made a few changes. Here are the changes I've made: 

1) Changed the movement of the character, the character moves by following the mouse position so it moves by mouse 
2) Added a shooting ability, the player can shoot tiny laser balls at enemies
3) Changed the apperance to a space theme, I drew the background, the astronaut, the meteors, aliens and star drops
4) Added item drops (stars) so players can pick up (was meant to use as currency but didn't have time for that update)
5) Changed the Aliens movement, it now has the ability to find follow the position of player
6) Added sound effects and music for the game
